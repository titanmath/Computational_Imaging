Avant les images, un seul coefficient. On observe un nombre $b$, qui peut être un gradient bruité, et l’on cherche
$$
\hat x = \arg\min_x \; \tfrac12 (x - b)^2 + \lambda\, \psi(x).
$$
Pour chacune des trois pénalités, on peut résoudre à la main en annulant la dérivée, ou en comparant les cas pour L1 et L0.

<Formule titre="Les trois solutions">
$$
\psi = x^2 :\; \hat x = \frac{b}{1 + 2\lambda}
\qquad
\psi = |x| :\; \hat x = \operatorname{sign}(b)\max(|b| - \lambda, 0)
\qquad
\psi = \mathbf 1[x \ne 0] :\; \hat x = \begin{cases} b & \text{si } b^2 > 2\lambda \\ 0 & \text{sinon}\end{cases}
$$

- L2² : un **rétrécissement** proportionnel, jamais exactement nul ;
- L1 : le <Terme en="soft thresholding">seuillage doux</Terme> retire $\lambda$ à tout coefficient et annule ceux qui sont sous $\lambda$ ;
- L0 : le <Terme en="hard thresholding">seuillage dur</Terme> garde les coefficients tels quels au-dessus de $\sqrt{2\lambda}$ et annule les autres.
</Formule>

<Concept titre="Le lien avec les images">
Dans une image, les gradients jouent le rôle de ces coefficients : beaucoup de petits gradients dus au bruit, quelques grands sur les bords. Un a priori L1 ou L0 sur les gradients se comporte comme un seuillage : il **annule les petits gradients**, ce qui crée des aplats, et **garde les grands**, ce qui garde les bords. Un a priori L2² rabote tout, bords compris. Le vrai problème d’image couple les pixels voisins : il faut un algorithme itératif, mais l’intuition reste la même.
</Concept>
